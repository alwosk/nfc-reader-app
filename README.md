# NFC 출퇴근

직원별 NFC 스티커를 공용폰에 찍어 출퇴근을 기록하고, Tailscale로 Windows PC에 전송합니다. 직원 폰용 앱과 웹 관리자 페이지는 없습니다.

## 다운로드 · v0.3.0

비공개 저장소에서 **Code → Download ZIP**으로 전체를 받거나 아래 파일을 다운로드하세요.

- [공용폰 설치용 APK](dist/attendance-v0.3.0.apk)
- [Windows 근태 수신기](dist/windows-receiver-v0.3.0.zip) — Python 3.12 이상, 3.14 지원. `install.cmd` → `start.cmd`
- [직원용 설명서 PDF](dist/employee-guide.pdf) / [Typst 원본](docs/employee.typ)
- [관리자용 설명서 PDF](dist/admin-guide.pdf) / [Typst 원본](docs/admin.typ)

## 이번 변경

- 참고 이미지에 맞춘 **검은 배경·흰 테두리·큰 출근/퇴근 버튼**. 태그 안내와 결과는 버튼 아래에 표시합니다.
- 우측 상단 **☰ 메뉴**를 열면 PC 전송, 관리자, 미전송 건수와 PC 연결 상태가 나타납니다.
- PC 설정의 **엑셀 저장 폴더 → 폴더 변경**으로 저장 위치를 바꿉니다. 재시작 후에도 유지되며 전체 기록을 새 위치에 생성합니다. 이전 파일과 DB는 그대로 둡니다.

## 기존 기능

- 긴 연결 암호 대신 **5분간 유효한 숫자 6자리 일회용 코드**를 입력합니다. 이후 연결은 자동입니다. 5번 틀리면 새 코드를 발급해야 합니다.
- 앱·화면·문서의 특정 기기 모델명 표기를 없앴습니다. 앱 이름은 **출퇴근**, PC 프로그램은 **근태 수신기**입니다.
- **창을 닫아도 백그라운드 수신**합니다. 작업표시줄 알림 영역에서 설정 열기·전송 요청·완전 종료를 할 수 있습니다.
- 설치 시 **Windows 로그인 후 창 없이 자동 실행**하도록 등록합니다. 설정 체크박스로 해제할 수 있습니다. VPN 연결이 늦으면 자동 재시도합니다.
- 엑셀 다시 만들기·다른 양식에 넣기·DB 백업 버튼을 제거했습니다. 월별 XLSX는 자동 갱신됩니다.

## 업데이트

기존 PC 수신기를 완전히 종료하고 새 ZIP을 푼 뒤 `install.cmd`를 다시 실행하세요. 신규 라이브러리와 시작프로그램 등록을 갱신합니다. 기존 PC 데이터 폴더와 연결 설정을 이어서 사용합니다.

APK는 **기존 앱 위에 설치**하세요. 설치 ID와 서명을 유지해 직원 등록·근태 기록·기존 연결을 보존합니다. 앱을 삭제하지 마세요.

## 기본 동작

출근/퇴근 버튼 선택 후 태그하며 직원당 하루 각 1회, 한국 시간으로 기록합니다. PC가 꺼져 있어도 폰에 저장합니다. 약 1시간 주기·폰의 전송 버튼·PC 전송 요청으로 미전송 기록을 보냅니다. PC는 저장 완료 후 확인 응답을 보내고 중복 전송을 제거합니다.

엑셀 열은 `직원이름 / 시간 / 출근인지 퇴근인지`입니다. 열어둔 파일 때문에 갱신이 막히면 닫은 후 자동 재시도합니다. PIN 관리자 메뉴에서 태그 관리·누락 입력·같은 날짜의 시각 정정이 가능합니다.

## 확인 범위

Android 12 공용폰과 Windows 11을 대상으로 합니다. 실제 NFC 인식, Windows 알림 영역/자동 실행, Tailscale 연결은 현장에서 확인해야 합니다. 삼성월렛 디지털 키 호환성은 미확정이며, 기본 수단은 스티커입니다.

APK는 debug 서명 시험판입니다. 정식 운영 서명 키 전환은 별도 계획이 필요합니다. 직원 동명이인은 이름에 구분 표기를 넣고, 자정을 넘기는 근무는 지원하지 않습니다. 자동 백업·직원 명부 복원·급여 계산은 제공하지 않습니다.

## 개발

Android: JDK 17+, SDK 35, Gradle 8.13 / AGP 8.9.2. `android`에서 `./gradlew assembleDebug lintDebug testDebugUnitTest`.
PC: Python 3.12 이상. `pip install -r pc/requirements.txt`, Windows에서 `python pc/app.py`.
검증: `python -m unittest discover -s tests -v`.
문서: Noto Sans CJK KR 폰트와 Typst. `typst compile docs/admin.typ dist/admin-guide.pdf`.

PC는 Tailscale IPv4의 TCP 8765에서만 수신합니다. 일회용 코드는 관리자 화면에서 발급할 때만 유효하며 실제 통신 인증 정보는 앱끼리 교환합니다. 근태 데이터·연결 정보·서명 키는 저장소에 넣지 않습니다.
