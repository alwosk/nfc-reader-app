# NFC 출퇴근

직원별 NFC 스티커를 공용폰에 찍어 출퇴근을 기록하고, 같은 내부 네트워크 또는 Tailscale로 Windows PC에 전송합니다. 직원 폰용 앱과 웹 관리자 페이지는 없습니다.

- **[폰용 v0.4.0 APK 다운로드](https://github.com/alwosk/nfc-reader-app/raw/refs/heads/main/dist/attendance-v0.4.0.apk)** — 새 서명 키로 서명한 설치 파일.
- **[Windows 수신기 v0.4.0 ZIP 다운로드](https://github.com/alwosk/nfc-reader-app/raw/refs/heads/main/dist/windows-receiver-v0.4.0.zip)** — 압축 해제 후 `pc/install.cmd` → `pc/start.cmd`. Python 3.12 이상이 필요합니다. 기존 v0.3.0 수신기는 내부망 연결을 지원하지 않습니다.
- [파일 SHA-256](dist/SHA256SUMS.txt)

**기존 v0.3.1이 설치된 폰에는 이 APK를 덮어 설치할 수 없습니다.** 두 APK의 서명이 다릅니다. 기존 앱을 삭제하면 폰의 직원 등록·근태 기록이 지워지므로 먼저 필요한 데이터를 보존하세요. v0.3.1에서 전환하려면 PC 전송·데이터 보존 여부를 먼저 확인하고 기존 앱을 삭제한 뒤 새로 설치해야 합니다. 폰의 직원·태그 등록과 연결 설정은 다시 해야 합니다. 앞으로 v0.4.0 위에 업데이트할 때는 이번에 만든 동일한 서명 키를 사용합니다.

이 APK는 [빌드·lint·테스트를 통과한 CI 결과물](https://github.com/alwosk/nfc-reader-app/actions/runs/38492387258)을 별도의 고정 서명 키로 다시 서명한 파일입니다. 앱 자체는 debug 빌드입니다. 파일을 main에 보관하므로 Actions 아티팩트를 찾지 않고 위 링크에서 받을 수 있습니다.

## 내부망 연결 · v0.4.0

같은 공유기에 연결된 공용폰과 PC는 Tailscale 없이 연결할 수 있습니다. PC는 유선, 폰은 Wi-Fi여도 됩니다.

1. 위 v0.4.0 APK와 최신 `pc` 폴더를 사용하세요. v0.3.1이 설치된 폰은 위 서명 변경 안내를 먼저 확인하세요. 아래의 기존 v0.3.x 배포본은 내부망 연결을 지원하지 않습니다.
2. PC에서 `install.cmd` → `start.cmd`를 실행합니다. **주소 찾기**에서 공용폰과 연결된 내부망 주소를 선택하고 **설정 저장**을 누릅니다. 직접 입력하려면 `ipconfig`의 해당 어댑터 IPv4 주소를 사용합니다.
3. 신뢰하는 사내 네트워크의 Windows 네트워크 프로필을 **개인**으로 설정합니다. 관리자 PowerShell에서 다음 명령의 두 IP를 실제 주소로 바꿔 실행합니다.
   ```powershell
   .\pc\allow-lan.ps1 -PhoneIP 192.168.0.20 -PcIP 192.168.0.10
   ```
   PC의 TCP 8765를 해당 공용폰에만 허용합니다. 규칙 제거: `Get-NetFirewallRule -DisplayName 'Attendance via LAN' | Remove-NetFirewallRule`.
4. 수신기에서 **새 연결 코드**를 발급하고, 폰 관리자 연결 설정에 `http://192.168.0.10:8765`처럼 실제 PC 주소와 6자리 코드를 입력합니다. 기존 Tailscale 주소에서 내부 IP로 바꿀 때도 새 코드로 연결합니다.
5. 폰에서 **PC로 지금 전송**을 누르고 PC의 엑셀 기록을 확인합니다.

공유기의 게스트 Wi-Fi/기기 간 통신 차단이 있으면 연결되지 않을 수 있습니다. PC와 공용폰에 DHCP 주소 예약을 설정하면 주소 변경에 따른 연결·방화벽 재설정을 줄일 수 있습니다. 주소가 바뀌면 수신기·폰 연결 주소 및 방화벽 규칙을 갱신하세요.

내부망 모드는 HTTP로 통신하므로 신뢰하는 네트워크에서 사용합니다. 전송 암호화가 필요한 환경이나 서로 다른 네트워크에서는 기존 Tailscale 연결을 사용할 수 있습니다. 인터넷 포트포워딩은 필요하지 않습니다.

## 이번 변경

- **밝은 배경·파란 출근 버튼·빨간 퇴근 버튼**. 외곽 프레임은 없으며, 선택한 버튼을 다시 누르면 선택이 해제됩니다. 태그 안내와 결과는 버튼 아래에 표시합니다.
- 우측 상단 **☰ 메뉴**를 열면 PC 전송, 관리자, 미전송 건수와 PC 연결 상태가 나타납니다.
- PC 설정의 **엑셀 저장 폴더 → 폴더 변경**으로 저장 위치를 바꿉니다. 재시작 후에도 유지되며 전체 기록을 새 위치에 생성합니다. 이전 파일과 DB는 그대로 둡니다.

## 기존 기능

- 긴 연결 암호 대신 **5분간 유효한 숫자 6자리 일회용 코드**를 입력합니다. 이후 연결은 자동입니다. 5번 틀리면 새 코드를 발급해야 합니다.
- 앱·화면·문서의 특정 기기 모델명 표기를 없앴습니다. 앱 이름은 **출퇴근**, PC 프로그램은 **근태 수신기**입니다.
- **창을 닫아도 백그라운드 수신**합니다. 작업표시줄 알림 영역에서 설정 열기·전송 요청·완전 종료를 할 수 있습니다.
- 설치 시 **Windows 로그인 후 창 없이 자동 실행**하도록 등록합니다. 설정 체크박스로 해제할 수 있습니다. VPN 연결이 늦으면 자동 재시도합니다.
- 엑셀 다시 만들기·다른 양식에 넣기·DB 백업 버튼을 제거했습니다. 월별 XLSX는 자동 갱신됩니다.

## 업데이트

기존 PC 수신기를 완전히 종료하고 새 ZIP을 푼 뒤 `install.cmd`를 다시 실행하세요. 신규 라이브러리와 시작프로그램 등록을 갱신합니다. 기존 PC 데이터 폴더와 연결 설정을 이어서 사용합니다.

APK를 기존 앱 위에 설치하려면 **설치 ID와 서명이 모두 같아야 합니다**. v0.3.1 → v0.4.0은 서명 키 변경으로 덮어 설치할 수 없으며, 데이터 보존 여부를 확인한 후 새로 설치해야 합니다. v0.4.0 이후에는 이번에 만든 키를 계속 사용해야 기록과 설정을 보존하며 업데이트할 수 있습니다.

## 기본 동작

출근/퇴근 버튼 선택 후 태그하며 직원당 하루 각 1회, 한국 시간으로 기록합니다. PC가 꺼져 있어도 폰에 저장합니다. 약 1시간 주기·폰의 전송 버튼·PC 전송 요청으로 미전송 기록을 보냅니다. PC는 저장 완료 후 확인 응답을 보내고 중복 전송을 제거합니다.

엑셀 열은 `직원이름 / 시간 / 출근인지 퇴근인지`입니다. 열어둔 파일 때문에 갱신이 막히면 닫은 후 자동 재시도합니다. PIN 관리자 메뉴에서 태그 관리·누락 입력·같은 날짜의 시각 정정이 가능합니다.

## 확인 범위

Android 12 공용폰과 Windows 11을 대상으로 합니다. 실제 NFC 인식, Windows 알림 영역/자동 실행, Tailscale 연결은 현장에서 확인해야 합니다. 삼성월렛 디지털 키 호환성은 미확정이며, 기본 수단은 스티커입니다.

APK는 debug 빌드이며, v0.4.0부터 별도의 고정 서명 키를 사용합니다. 직원 동명이인은 이름에 구분 표기를 넣고, 자정을 넘기는 근무는 지원하지 않습니다. 자동 백업·직원 명부 복원·급여 계산은 제공하지 않습니다.

## 개발

Android: JDK 17+, SDK 35, Gradle 8.13 / AGP 8.9.2. `android`에서 `./gradlew assembleDebug lintDebug testDebugUnitTest`.
PC: Python 3.12 이상. `pip install -r pc/requirements.txt`, Windows에서 `python pc/app.py`.
검증: `python -m unittest discover -s tests -v`.
문서: Noto Sans CJK KR 폰트와 Typst. `typst compile docs/admin.typ dist/admin-guide.pdf`.

PC는 선택한 내부망 IPv4(10/8, 172.16/12, 192.168/16) 또는 Tailscale IPv4(100.64/10)의 TCP 8765에서 수신합니다. 공인 IP, 루프백, 0.0.0.0은 설정할 수 없습니다. 일회용 코드는 관리자 화면에서 발급할 때만 유효하며 실제 통신 인증 정보는 앱끼리 교환합니다. 근태 데이터·연결 정보·서명 키는 저장소에 넣지 않습니다.
